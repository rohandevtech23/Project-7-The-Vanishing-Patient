# 🏥 The Vanishing Patient – Hospital Analytics Project

> An end-to-end Data Analytics project that transforms raw hospital patient data into actionable business insights using Excel, Python, and Power BI.

---

## 📌 Project Overview

Healthcare organizations generate massive amounts of patient data every day. This project demonstrates the complete Data Analytics workflow—from data cleaning and exploration to interactive dashboard creation.

The goal of this project is to analyze hospital patient records, identify trends, discover hidden patterns, and present meaningful insights through a professional Power BI dashboard.

---

## 🎯 Objectives

- Clean and preprocess raw hospital data
- Perform Exploratory Data Analysis (EDA)
- Engineer useful features
- Identify patient and hospital trends
- Build an interactive Power BI dashboard
- Generate business insights for decision-making
